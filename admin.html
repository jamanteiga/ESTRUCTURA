🏗️ Estructura mínima editable

Qué crea de golpe "Generar estructura mínima" en el árbol, según el tipo de nodo. Formato JSON: cada tipo tiene una lista de hijos (tipo, y opcionalmente codigo, nombre e hijos anidados). Si algo sale mal, el árbol sigue usando siempre la definición de fábrica de siempre.

📅 Importación masiva de festivos

Columnas: Fecha, Sede (vacío = festivo nacional), Descripcion, Ambito (nacional / autonomico / local).

🌴 Importación masiva de ausencias

Columnas: Usuario (su nombre de usuario o nombre completo), FechaInicio, FechaFin, Motivo (opcional).

⏱️ Horas de trabajo por usuario

Para cada tarea, se cuenta el tiempo entre que se puso "en proceso" y se terminó (o el momento actual, si sigue en proceso todavía), y se suma por usuario dentro del periodo elegido. No descuenta paradas dentro de ese tiempo (una tarea abierta varios días sin tocarla cuenta esas horas igual).
