📥 Importar estructura desde Excel

Solo ADMIN puede importar estructura.

1. Descarga la plantilla

La plantilla tiene estas columnas: Ruta, Tipo y Nombre (Descripcion y Orden son opcionales). La Ruta es el camino completo desde el nodo destino hasta esta fila, separando cada nivel con "/" — el último tramo es el código de esta fila (p.ej. SB2/UA2/1027: cuelga de SB2/UA2, y su propio código es 1027). Si la ruta empieza por el código del nodo destino, ese primer tramo se ignora (para poder escribir rutas absolutas desde el Buque aunque hayas elegido un destino más abajo). Cada tramo intermedio de la ruta (p.ej. SB2/UA2) tiene que existir ya, bien porque es una fila anterior de este mismo Excel, bien porque ya existe en el árbol.

2. Elige dónde se añadirá

3. Sube tu fichero Excel

4. Revisa antes de importar
