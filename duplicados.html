🔍 Comprobar nombres/códigos repetidos

Solo ADMIN puede usar esta herramienta.

Revisa toda la estructura activa del árbol (todos los Buques) y agrupa los nodos que comparten el mismo Código o el mismo Nombre, mostrando la ruta completa de cada uno. Que aparezcan varios con el mismo código no es necesariamente un error — por ejemplo, "UA1" puede existir legítimamente en varios Subbloques distintos — pero te permite revisarlo de un vistazo y confirmar que todo está donde debe.
